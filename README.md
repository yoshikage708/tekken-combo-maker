# TEKKEN 8 Combo Card Maker（CCM）

鉄拳8のコンボや連携を、読みやすいアイコン／テンキー文字形式のカードとして作成・保存できる無料の非公式ファンメイドWebツールです。

## 主な機能

- コンボ／連携カードの切り替え
- 短押し・長押し方向、4点式攻撃ボタン、前ステ／バクステ
- 方向キーのアイコン表示／鉄拳式テンキー文字表示の切り替え
- キャラクター固有構え、状態タグ、壁・システム入力
- 回数、技注釈、単体／範囲の注釈番号
- コマンドの選択、連続挿入、選択削除、末尾削除
- メモ文章内への方向・攻撃・注釈番号挿入
- レシピの端末保存、コピー、名前変更、削除
- メインキャラクターの端末保存
- PC／iPhone／Android向け画像保存・共有
- 長いレシピの保存画像自動縮小
- 使い方ページ

## 構成

- `data.js`：キャラクター、構え、タグ、コマンド定義
- `numpad-layout.js`：方向表示の共通`>`区間計画と、テンキー文字表示の設定
- `renderer.js`：画面表示とメモ表示
- `editor.js`：入力・挿入・編集処理
- `storage.js`：レシピとメインキャラクターの端末保存
- `card-renderer.js`：PNGカード描画と端末別保存
- `app.js`：画面初期化とイベント接続

ビルド処理やサーバーは不要です。GitHub Pagesへそのまま配置できます。

## 公開方法（GitHub Pages）

1. ファイル一式をGitHubリポジトリのルートへ置く。
2. `Settings` → `Pages` を開く。
3. `Deploy from a branch` を選ぶ。
4. `main` と `/(root)` を選び、保存する。

## 保存データ

レシピとメインキャラクターはブラウザのlocalStorageへ保存します。ユーザー登録やサーバーへの個人情報保存は行いません。
